# The Threshold · Coffeehouse Portal

A public, iPad-friendly reading and exploration portal inspired by the spirit of Parisian literary coffeehouses.

## Privacy boundary

This repository is **public**. Do not commit personal journals, private notes, credentials, or contents copied from the private `stephs-stuff/the-threshold` repository. Private writing stays in that separate repository.

## Publishing

In GitHub repository **Settings → Pages**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then Save. The expected address is https://stephs-stuff.github.io/threshold-portal/ once GitHub Pages deploys.

## First reading

Plato, *Republic*, Book VII, Benjamin Jowett translation. Full text: https://www.gutenberg.org/ebooks/55201 . Check rights for any new edition or translation before reproducing it.

## Design

Responsive HTML/CSS, no build process, no tracking scripts, keyboard-accessible navigation, and reduced-motion support. The web manifest supports an app-like Home Screen launch; offline availability is not yet implemented.
